pyStarburst99

STARBURST99 is a population synthesis code tailored to predict the integrated properties or observational characteristics of star-forming galaxies. I have recently updated STARBURST99 to port the code to python and include new evolutionary tracks both rotating and non-rotating at a range of low metallicity environments and up to 300-500 solar masses. The evoltionary tracks are complemented with a corresponding grid of new synthetic SEDs produced with FASTWIND. The first paper presenting new predictions for integrated galactic properties has been accepted for publication at ApjS and the code is available on Github and Colab.
